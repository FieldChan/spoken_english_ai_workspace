# Michael’s Tech Workplace English Handbook

Chapter 5: GitHub / PR / Code Review

范围：基于你在真实工作场景中围绕 GitHub、fork repo、PCM setup、PR review、deployment、support issue 等场景的高频英文沟通整理。

### 1. 创建 GitHub issue

中文意图：想告诉对方你已经建好了 issue/request。

推荐英文表达：I’ve already created a GitHub issue for this.

Google Chat 版：I already opened an issue for this.

GitHub comment 版：I’ve already created a GitHub issue for this and documented the request there.

可替换模板：I’ve already created a {GitHub issue / support request} for this.

常见错误替换：中式：I have created a request.
更自然：I’ve already created a GitHub issue for this.

### 2. 请求别人 review PR

中文意图：请对方帮忙看代码。

推荐英文表达：Would you mind helping review the PR when you have time?

Google Chat 版：Could you take a look at the PR when you get a chance?

GitHub comment 版：I’d appreciate it if you could review the PR when you have time.

可替换模板：Would you mind helping review the PR when you have time?

常见错误替换：中式：Can you review my code?
更自然：Would you mind helping review the PR when you have time?

### 3. 说明已经 assign reviewer

中文意图：告诉对方已经 assign 给他了。

推荐英文表达：I’ve opened a PR and assigned it to you.

Google Chat 版：I opened a PR and assigned it to you.

GitHub comment 版：I’ve opened a PR and assigned it to you for review.

可替换模板：I’ve opened a PR and assigned it to {reviewer}.

常见错误替换：中式：I send PR to you.
更自然：I’ve opened a PR and assigned it to you.

### 4. 询问 request 是否 approved

中文意图：想知道审批是否通过。

推荐英文表达：Do you know if the request has already been approved?

Google Chat 版：Do you know if the request is approved yet?

GitHub comment 版：Could you please let me know whether the request has already been approved?

可替换模板：Do you know if the {request} has already been approved?

常见错误替换：中式：Request approved?
更自然：Do you know if the request has already been approved?

### 5. 询问现在能不能 push code

中文意图：想确认是否可以开始 push。

推荐英文表达：Is it okay for me to try pushing our code to the forked repo now?

Google Chat 版：Is it fine if I go ahead and try pushing our code now?

GitHub comment 版：Could you please confirm whether it is okay for me to start pushing our code to the forked repo now?

可替换模板：Is it okay for me to {push / submit / sync} the code now?

常见错误替换：中式：Can I push code now?
更自然：Is it okay for me to try pushing our code to the forked repo now?

### 6. 回应提醒：暂时不要 push

中文意图：对方提醒先别 push，你要确认会等待。

推荐英文表达：Got it, I won’t push anything until the request gets approved.

Google Chat 版：Got it, I’ll wait until it’s approved.

GitHub comment 版：Understood. I won’t push any code until the request has been approved.

可替换模板：I won’t {push / proceed / sync} anything until {condition}.

常见错误替换：中式：I will not push code now until approve.
更自然：I won’t push anything until the request gets approved.

### 9. 解释代码部署流程

中文意图：你理解的 deployment workflow 是什么。

推荐英文表达：My understanding is that I submit the code, you review it, and then we proceed with deployment. Is that correct?

Google Chat 版：Just to double-check — I open the PR, you review it, and then we deploy, right?

常见错误替换：中式：The process is like this, right?
更自然：My understanding is that... Is that correct?
